# The joke the reviewer laughs at

My entry for the make.fun bounty
[the-joke-the-reviewer-laughs-at-20261121-0329](https://make.fun/bounty/the-joke-the-reviewer-laughs-at-20261121-0329):
a tiny Python program that writes one one-line joke about working beside AI
coding agents to `/output/entry.txt`.

## Run it

```sh
python3 main.py            # writes /output/entry.txt
MAKEFUN_OUTPUT_DIR=out python3 main.py   # writes out/entry.txt
```

The joke, in one breath: reviewing an agent's diff and being reviewed by it
turn out to be the same polite fiction — both sides nod, both sides approve.
